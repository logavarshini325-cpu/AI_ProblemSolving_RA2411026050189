## Problem 8: Smart Navigation System

This program finds a path between a start node and a goal node using graph traversal techniques.

It uses:
- Breadth First Search (BFS) to find the shortest path
- Depth First Search (DFS) to explore nodes depth-wise

## Problem 11: Cost-Based Decision System

This program finds the least cost path between two nodes in a weighted graph.

It uses:
- Uniform Cost Search (UCS) algorithm

The user enters the start and goal nodes, and the system calculates the optimal path with minimum total cost.
The user enters the start and goal nodes, and the system displays the path found by both algorithms.
